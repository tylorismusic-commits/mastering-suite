# Changelog

## 0.6.0 — 2026-11-19

- New **Output** page with stereo width (0–200%) and a Stereo / M-S / Mid /
  Side monitor matrix.
- Dither at 16 or 24 bits with TPDF or noise-shaped output.
- Delta audition: subtracts the latency-aligned dry signal so processing
  differences can be heard in isolation.
- Streaming loudness targets (-9, -14, -16, -23 LUFS) with a live match
  offset on the Loudness and Output pages.
- Reference spectrum overlay on the Spectrum page with **REF SET** and
  **CLR**.

## 0.5.1 — 2026-11-19

- User preset bank: save, rename, duplicate, delete, export and drag-drop
  import, alongside the factory presets.
- Preset files live in `~/.config/MasteringSuite/presets` and export to
  `~/Documents/Mastering Suite Presets`.
